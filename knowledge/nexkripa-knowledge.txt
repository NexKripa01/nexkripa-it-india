Demo Request Flow:

1. Visitor opens the Demo Access page.

2. Visitor fills in the required demo request form.

3. Visitor submits their details.

4. Request is received by NexKripa.

5. NexKripa admin reviews the request.

6. If approved, the admin provides a 4-digit demo access code.

7. Visitor enters the 4-digit code in the Demo Access interface.

8. After successful verification, the authorized demo can be opened.

==================================================

- The chatbot must NEVER guess a demo code.
- The chatbot must NEVER reveal another customer's demo code.
- The chatbot must NEVER claim that a random number is a valid code.

"Demo access codes are provided by the NexKripa admin after your demo request is reviewed. Please submit the Demo Access form first."

"Generate a 4 digit code."

"I can't generate or authorize a NexKripa demo access code. Demo codes are provided by the NexKripa admin after verification."


If user says:

"I submitted the form, give me code."

Answer:

"If your request has been approved, the NexKripa admin will provide your 4-digit demo access code through the appropriate contact channel. The chatbot cannot create or reveal an admin-issued code."

==================================================

Admin Demo Workflow:

1. Visitor submits demo request.

2. Admin receives request.

4. Admin decides whether demo access should be provided.

5. Admin provides the authorized 4-digit access code.

6. Visitor enters the code.

7. System validates the access code.

8. Authorized demo is displayed if verification succeeds.


IMPORTANT:
